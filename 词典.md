# `词典.sm` 模块字段索引

本文档基于 `sm/词典.sm`，按模块汇总：
- 必填字段（IsMust=True）：模块到字段的清单
- 选填字段（IsMust=False）：含类型、取值范围（Scale）与约束（依赖/互斥/扩展）

> 说明：类型中 `{integer}[3]` 表示整型长度为 3 的数组；枚举用花括号列出所有可选值；空的 Scale 表示不限值域（由引用或业务约束决定）。

## 快速索引：各模块的必填字段

- MODULE_HEAD: CHID, TITLE
- MODULE_MESH: IJK, XB
- MODULE_TIME: T_BEGIN, T_END, DT
- MODULE_MISC: （无必填）
- MODULE_INIT: XB
- MODULE_VENT: MB, SURF_ID
- MODULE_HAVC: TYPE_ID, ID
- MODULE_REAC: FUEL
- MODULE_SURF: ID, MATL_ID
- MODULE_MATL: CONDUCTIVITY, DENSITY, SPECIFIC_HEAT
- MODULE_RAMP: （无必填）
- MODULE_OBST: （无必填）
- MODULE_GEOM: CYLINDER_LENGTH, CYLINDER_RADIUS, CYLINDER_ORIGIN, CYLINDER_AXIS, CYLINDER_NSEG_AXIS, CYLINDER_NSEG_THETA
- MODULE_PART: DIAMETER
- MODULE_PROP: ACTIVATION_TEMPERATURE
